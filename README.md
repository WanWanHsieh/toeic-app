# 多益單字 App

用 KK 音標、拼音拆解和間隔重複（FSRS），把多益單字記牢。這是一個 PWA（可安裝的網頁 App），手機加到主畫面就能像 App 一樣使用，也能離線。

## 在電腦上執行

```bash
python -m http.server 5180
```

開啟 http://localhost:5180

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `data/words.js` | 單字資料（目前 20 字範例） |
| `js/fsrs.js` | FSRS 複習排程（v4.5 預設參數，簡化版） |
| `js/app.js` | 畫面與學習流程 |
| `css/style.css` | 樣式（支援深色模式） |
| `sw.js` / `manifest.webmanifest` | 離線快取與安裝設定 |

## 單字資料格式

每個字的 `chunks` 把單字拆成「字母 → KK 發音」的小段，所有 `t` 串起來必須等於 `word`，所有 `k` 串起來必須等於 `kk`（去掉括號和重音符號）。

```js
{ t: "ti", k: "ʃɪ", s: 1, n: "ti 在這裡念 [ʃɪ]" }
// t: 字母　k: KK 發音　s: 1 主重音 / 2 次重音　silent: true 不發音　n: 提示文字
```

## 學習方式

- **看字回想**：看單字和 KK 先自己唸、想意思，再看答案自評（忘記／困難／記得／簡單）
- **聽音拼字**：聽發音拼出單字，自動判斷對錯；學過「看字回想」後才會出現

學習進度存在瀏覽器的 localStorage，清除瀏覽器資料會一起清掉。
